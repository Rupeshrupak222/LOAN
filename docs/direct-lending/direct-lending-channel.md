# Direct Lending Channel Configuration

## 1. Channel Differentiation
Adyapan Lending OS recognizes multiple origination channels:
- `DIRECT_WEB`: Consumer web portal origination.
- `MOBILE_APP`: Native iOS/Android app channel (Phase 18).
- `PARTNER_LSP`: Phase 8 Partner/LSP integrations.
- `BRANCH_PORTAL`: Branch officer / loan officer assisted sourcing.

Direct lending events are tagged with channel metadata so that Phase 14 Analytics and Management Information Systems can compute channel-specific conversion funnels, delinquency rates, and portfolio profitability.
