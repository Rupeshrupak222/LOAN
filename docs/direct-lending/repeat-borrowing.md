# Repeat Borrowing Intelligence

## 1. Fast-Track Repeat Loan Engine
Existing customers with a proven repayment track record are evaluated automatically for subsequent loan approvals:
- **Zero-DPD Validation**: Customer must have 0 current DPD across all active loan schedules.
- **Concurrent Active Loan Limit**: Enforces a maximum of 2 concurrent active loans to prevent borrower over-indebtedness.
- **On-Time Payment Multiplier**:
  - ≥ 1 closed loan or ≥ 3 on-time payments: 2.0× limit enhancement.
  - ≥ 2 closed loans and ≥ 6 on-time payments: 2.5× limit enhancement.
- **Instant Pre-Approval Banner**: Displayed prominently on the borrower dashboard when eligible.

---

## 2. Re-evaluation Safeguards
Repeat borrowing is **never** an unverified rubber-stamp:
- Fraud rules are re-evaluated.
- Total exposure is checked against the borrower's income.
- Current active delinquencies block new repeat loan origination.
